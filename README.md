# MAST-SA1
The changes that took place:
The Restaurant Manager App transformed from a basic add-and-view app into a complete menu management system. Full CRUD was added dishes can now be edited and deleted. Live search and course filtering were also implemented allowing users to instantly narrow dishes by name and by Starter,Main,Dessert,with a Clear function to reset both. A statistics card now shows total items,average price,and counts per course,calculated directly from the dishes array. Consistent styling reusable functions,meaningful variable names and validation improved usability and code quality. Because state is lifted to App.tsx, every change reflects immediately, resulting in a functional, user-friendly and professional application ready for real restaurent use. This upgrade meets all the requirements and demonstrates proper React Native state management and navigation.
